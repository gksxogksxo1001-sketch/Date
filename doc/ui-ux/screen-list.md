# 화면 목록 및 IA (Screen List & Information Architecture)

## 1. 화면 목록 개요 (Screen Overview)

| 화면 ID | 화면명 | 핵심 역할 | 주요 인터랙션 및 구성 요소 |
| :--- | :--- | :--- | :--- |
| **SCR-01** | 랜딩 & 방 생성 홈 | 비회원 접속 ➔ 데이트 방 만들기 선택 | `<데이트 신청 방 만들기>` 히어로 CTA, 감성 가이드 문구 |
| **SCR-02** | 데이트 신청서 작성 모달/페이지 | 데이트 장소, 시간, 예산, 가게링크, 메시지 입력 | 만남 장소 폼, Date/Time picker, 예산 칩 선택, 가게 URL 입력 |
| **SCR-03** | 초대장 완결 및 공유 모달 | 초대장 링크 생성 및 공유 | 카카오톡/클립보드 초대 링크 복사, 미리보기 버튼 |
| **SCR-04** | 초대장 수신 카드 View | 상대방이 링크 클릭 시 확인하는 데이트 카드 | 장소/시간/예산 요약, 🔗 가게 바로가기 링크 버튼, `<데이트 수락하기>` CTA |

---

## 2. 화면별 와이어프레임 구조 (Wireframe Layout)

### SCR-02 데이트 신청서 작성 폼
```
+---------------------------------------------------+
|  💌 데이트 신청 방 만들기                          |
|                                                   |
|  [ 신청자 이름 ]    [ 받는 사람 이름 ]              |
|                                                   |
|  [ 만날 장소 ]      예: 성수동 까페거리           |
|                                                   |
|  [ 약속 날짜 & 시각 ] 2026-09-10 18:00            |
|                                                   |
|  [ 예상 예산 ]                                    |
|  (3만원 이하) (5~10만원) (15만원+) (자유)           |
|                                                   |
|  [ 가게/장소 관련 링크 (선택) ]                   |
|  예: https://map.naver.com/...                    |
|                                                   |
|  [ 초대 메시지 ]                                  |
|  맛있는 저녁 먹고 같이 산책해요!                   |
|                                                   |
|  [ ✨ 데이트 초대장 만들기 및 링크 생성 ]          |
+---------------------------------------------------+
```

### SCR-04 초대장 수신 카드 View (상대방 시점)
```
+---------------------------------------------------+
|               💖 Love Invitation 💖               |
|                                                   |
|   "OO아, 나와 데이트할래?"                         |
|   From. XX                                        |
|                                                   |
|  📍 장소: 성수동 카페거리                          |
|  ⏰ 일시: 2026년 9월 10일 (목) 오후 6:00          |
|  💰 예상 예산: 5~10만원 범위                      |
|                                                   |
|  🔗 추천 가게 정보 보러가기:                       |
|     [ 🍽️ 맛집/카페 페이지 링크 열기 (새창) ]       |
|                                                   |
|  💌 메시지: "맛있는 저녁 먹고 같이 산책해요!"      |
|                                                   |
|            [ 💖 데이트 신청 수락하기! ]            |
+---------------------------------------------------+
```
