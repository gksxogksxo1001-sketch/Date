# UI Spec: 인터랙티브 실링 왁스 봉투 오프닝 & 뷰어 확장 (ui-spec-envelope)

## 1. 개요 및 설계 목적
데이트 초대장 수신자가 URL 링크를 열었을 때, 딱딱한 카드뉴스가 바로 뜨는 대신 **"너를 위해 준비한 소중한 편지"**라는 첫인상을 심어주기 위한 감성적인 3D 인터랙티브 봉투 연출입니다.

---

## 2. 화면 구성 요소 (Wireframe Layout)

```
+-------------------------------------------------------------+
| [DatePlanner 로고]                      [Skip (바로보기) >] |
|                                                             |
|                   [3D 봉투 컨테이너]                         |
|             +-------------------------------+               |
|             |          /\       /\          |               |
|             |         /  \ flap/  \         |               |
|             |        /    \   /    \        |               |
|             |       +-------V-------+       |               |
|             |       |  ( 붉은 실링 ) |       |               |
|             |       |  ( 왁스 스탬프) |      |               |
|             |       +---------------+       |               |
|             |                               |               |
|             |   To. [받는 사람 이름] 님      |               |
|             |   From. [보낸 사람 이름]      |               |
|             +-------------------------------+               |
|                                                             |
|           👆 실링 왁스를 터치하여 편지를 열어보세요           |
+-------------------------------------------------------------+
```

---

## 3. 인터랙션 시퀀스 (Interaction Flow)

1. **초기 진입**:
   - 화면 중앙에 부드러운 그림자와 함께 로맨틱 파스텔톤의 편지 봉투가 떠오름 (`fadeInUp` 0.8s)
   - 실링 왁스 버튼에 미세한 펄스(pulse) 애니메이션이 적용되어 터치를 유도
2. **실링 왁스 탭 / 클릭**:
   - 실링 왁스가 0.2초간 축소 후 '톡' 깨지는 효과 (Canvas 파티클 미세 조각 확산)
   - 봉투 상단 덮개(Flap)가 3D 원근법(`perspective: 1000px`, `rotateX(180deg)`)으로 위로 활짝 열림 (0.6s)
   - 봉투 내부에서 편지지(초대장 카드 뷰)가 위로 솟아오름 (`translateY(-80px)`, `scale(1.05)`)
   - 0.5초 후 봉투 오버레이 전체가 페이드아웃되며 스토리 뷰어 본문으로 매끄럽게 포커스 전환
3. **Skip 버튼 터치**:
   - 애니메이션을 건너뛰고 즉시 스토리 뷰어 첫 번째 코스 화면으로 진입

---

## 4. 디자인 토큰 및 시각 스타일
- **봉투 배경**: 고급 수입지 느낌의 크림/소프트 로즈 텍스처 (`#FFF9F5`, 테두리 `#EAD5C8`)
- **실링 왁스**: 메탈릭 딥 로즈/골드 그라데이션 (`linear-gradient(135deg, #C94C4C, #8B0000)`), 금박 하트 문양 음각
- **타이포그래피**: `Playfair Display` 및 `Cormorant Garamond` 감성 영문/한글 폰트 혼용
