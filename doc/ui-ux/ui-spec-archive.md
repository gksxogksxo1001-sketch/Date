# [UI Spec] 내 데이트 초대장 보관함 & 카카오 간편 로그인 명세서

## 1. 개요 (Overview)
- **화면명**: 상단 네비게이션 바 & 내 데이트 보관함 모달 (`#archiveModal`)
- **목적**: 사용자가 카카오 1초 간편 로그인으로 계정을 연동하고, 자신이 작성한 감성 데이트 초대장들을 보관함에서 확인, 열기, 링크 복사, 카카오톡 즉시 재전송할 수 있는 직관적인 대시보드 환경을 제공합니다.

---

## 2. 화면 구성 및 레이아웃 (Layout & Components)

### 1) 상단 글로벌 네비게이션 바 (`.global-navbar`)
- **위치**: 페이지 최상단 고정/플로팅 글래스모피즘 바 (`backdrop-filter: blur(12px)`)
- **주요 요소**:
  - **브랜드 로고 (`.nav-brand`)**: 나침반 아이콘 + `DatePlanner` 텍스트 (클릭 시 홈으로 이동)
  - **내 보관함 버튼 (`.nav-btn-archive`)**: 
    - 보관함 아이콘 + 텍스트 + 실시간 보관 개수 뱃지 (`.badge-count`)
  - **카카오 인증 영역 (`.nav-auth-container`)**:
    - **로그아웃 상태**: `[카카오 로그인]` 시그니처 옐로우 버튼 (`#FEE500`)
    - **로그인 완료 상태**: 카카오 원형 프로필 썸네일 (`.nav-avatar`) + 카카오 닉네임 (`.nav-nickname`) + 로그아웃 버튼 (`.nav-logout-btn`)

### 2) 내 데이트 보관함 모달 (`#archiveModal`)
- **컨테이너**: 와이드 모달 카드 (`.modal-card-large`, 최대 너비 640px)
- **헤더 영역**:
  - 타이틀: `내 데이트 보관함 💌`
  - 상태 안내문구: 로그인 상태에 따른 실시간 계정 안전 보관 뱃지 (`.badge-online`)
  - 닫기 아이콘 버튼 (`.modal-close-icon-btn`)
- **바디 영역**:
  - **초대장 카드 그리드 (`.archive-cards-grid`)**:
    - **테마 뱃지 (`.archive-theme-pill`)**: Warm Cozy / Romantic Rose / Midnight Navy
    - **생성 일시 (`.archive-date-tag`)**: 생성 시간 표시
    - **타이틀**: `To. 상대방이름 (From. 신청자이름)`
    - **데이트 정보 메타**: 데이트 예정일자, 지역, 예산 칩
    - **코스 요약 프리뷰 (`.archive-courses-preview`)**: 1차 ➔ 2차 ➔ 3차 장소 간략 요약
    - **하단 액션 버튼 그룹 (`.archive-card-actions`)**:
      - `[열기]`: 해당 스토리 초대장 뷰어 즉시 이동
      - `[링크복사]`: 원클릭 클립보드 복사
      - `[카톡 전송]`: 카카오톡 공유 피드 즉시 팝업
      - `[삭제]`: 확인 후 보관함에서 삭제
  - **빈 상태 (Empty State, `.archive-empty-state`)**:
    - 보관된 초대장이 없을 때 감성 편지 일러스트 + `[첫 데이트 초대장 만들기]` 유도 버튼

---

## 3. 사용자 인터랙션 (Interactions)
1. **카카오 1초 로그인**: 클릭 시 카카오 OAuth 팝업 실행 ➔ 로그인 성공 시 즉시 프로필 썸네일/닉네임 갱신 및 토스트 알림
2. **초대장 생성 연동**: 새 데이트 카드 생성 완료 시 자동으로 '내 보관함'에 최신순 추가 & 뱃지 카운트 실시간 증가
3. **원클릭 카톡 재전송**: 보관함에서 카톡 버튼 클릭 시 카카오 메시지 전송창 바로 호출
