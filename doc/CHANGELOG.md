## [2026-09-04] 신청자/수신자 역할 분리(Role Isolation) 및 수락 버튼 1회 잠금(One-time Lock) 적용

### 🔒 보안 및 역할 기반 UI 제어
- **신청자(작성자)와 공유받은 상대방 화면 완전 분리**:
  - 신청자(작성자)가 초대장을 열었을 때는 **[수락하기] 및 [조정 요청하기] 버튼이 표시되지 않음**
  - 대신 `"내가 만든 데이트 초대장입니다 (상대방 화면에서만 수락 버튼이 표시됩니다)"` 왕관 배너 및 **`[카카오톡으로 상대방에게 다시 보내기]`** 버튼 노출
- **수락 버튼 1회 클릭 시 영구 잠금 (One-time Acceptance Lock)**:
  - 상대방이 **[데이트 코스 완벽해! 수락하기]** 버튼을 클릭하면:
    1. 수락하기 버튼과 코스 조정 요청 버튼이 **즉시 영구 숨김 처리**되어 재클릭 방지
    2. 화면에 **`"데이트 약속을 수락하셨습니다! (확정됨 💖)"`** 완료 배너 표시
    3. **`[스토리 카드 이미지로 저장하기]` 버튼만 단독 노출**되어 일정을 캡처 보관할 수 있도록 UI 간소화
    4. **카카오톡 공유창이 1초 후 자동으로 오픈**되어 작성자에게 바로 수락 카톡 메시지를 보낼 수 있도록 연동
    5. Supabase `date_cards` 테이블에 `is_accepted = true` 상태를 실시간 업데이트하여 작성자의 [내 보관함]에도 수락 뱃지 반영

## [2026-09-04] 카카오톡 수락 답장 & 코스 조율 피드백 카톡 전송 연동 + 이모티콘 배열 최적화

### 💌 카카오톡 양방향 소통 기능 추가
- **데이트 코스 수락 답장 카톡 전송 (`sendAcceptKakaoBtn`)**:
  - 상대방이 [데이트 코스 완벽해! 수락하기] 버튼 클릭 시, 수락 모달에서 **`[💬 카카오톡으로 수락 답장 보내기]`** 버튼 지원
  - 카카오톡 공유 API를 통해 초대자에게 `"💖 [데이트 수락] OOO님이 데이트 코스를 수락했어요!"` 메시지 즉시 전송
  - 미지원 환경 대비 클립보드 자동 복사 폴백 지원
  - Supabase `date_cards` 및 로컬 보관함에 `is_accepted = true` 상태 실시간 업데이트
  - **내 데이트 보관함**에서 상대방이 수락한 초대장에 **`💖 상대방 수락 완료!`** 뱃지 자동 표시
- **일정/코스 조정 요청 카톡 전송 (`sendFeedbackKakaoBtn`)**:
  - [살짝 코스 조정 요청하기] 모달에서 제안 내용 작성 후 전송 시, **실제 카카오톡 공유창이 오픈되어 초대자에게 바로 카톡 발송**
  - 메시지: `"💌 [데이트 조율] OOO님의 코스 변경 제안: '...'"`, `[코스 확인하고 조율하기]` 원클릭 이동 버튼 포함
  - 클립보드 자동 복사 동시 지원으로 카톡 채팅방에 즉시 붙여넣기도 가능

### 🎨 이모티콘 & 버튼 레이아웃 정밀 개선
- **아이콘 및 이모티콘 중복 표시 버그 수정**:
  - `📷 📷 스토리 카드 이미지로 저장하기` ➔ `<i class="fa-solid fa-camera"></i> 스토리 카드 이미지로 저장하기`로 중복 카메라 아이콘 완전 제거
  - `💬 💬 카카오톡으로 초대장 보내기` ➔ FontAwesome 아이콘과 단일 텍스트로 정돈
  - 수락 버튼: `<i class="fa-solid fa-heart-circle-check"></i> 데이트 코스 완벽해! 수락하기`로 깔끔한 단일 하트 심볼 적용
- **스토리 헤더 뱃지 정돈**:
  - `1차 코스 - 맛집/식사`의 투박한 하이픈을 세련된 가운뎃점(`1차 코스 · 맛집/식사`)으로 변경
- **보관함 수락 뱃지 디자인**:
  - `💖 상대방 수락 완료!` 로즈 핑크 테마 뱃지 및 부드러운 하이라이트 효과 적용
