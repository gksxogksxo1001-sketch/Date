## [2026-09-04] 감성 랜딩(히어로) 페이지 추가

### ✨ 기능 추가
- **풀스크린 히어로 섹션**: 감성 데이트 실루엣 배경 이미지 + 서비스 소개 카피 + CTA 버튼
- **3단계 사용법 가이드**: ① 코스 작성 → ② 링크 생성 → ③ 카톡 전송 스텝 카드
- **주요 기능 소개 4종 카드**: 감성 테마 / 사진 업로드 / 스토리 뷰어 / 수락 폭죽 기능 소개
- **샘플 초대장 목업 미리보기**: 폰 프레임 내 자동 슬라이드 스토리 카드 데모
- **하단 CTA 섹션**: 추가 `데이트 초대장 만들기` 호출 버튼
- **랜딩 → 작성모드 전환**: CTA 클릭 시 랜딩 숨김 → 기존 폼 노출, smooth scroll
- **공유 링크 직접 진입**: `?card=` 토큰 URL 접속 시 랜딩 건너뛰고 바로 스토리 뷰어 진입

## [2026-09-04] 초기 구축 및 1차 배포

### ✨ 기능 추가
- **데이트 초대장 생성 모드**: 신청자/수신자 이름, 날짜, 지역, 코스(동적 추가/삭제), 예산, 메시지, 테마 선택 폼 구현
- **갤러리 이미지 첨부**: 캔버스 기반 이미지 압축(Canvas Compression) 후 코스별 최대 3장 업로드
- **URL Token 기반 공유**: Base64 + UTF-8 인코딩/디코딩 멀티 폴백 처리
- **인스타 스토리 페이저 뷰어**: 터치 스와이프 + 버튼 네비게이션 스토리 카드 슬라이더
- **데이트 수락 인터랙션**: 수락 버튼 → 축하 모달 표시
- **코스 조정 피드백 모달**: 커스텀 플로팅 드롭다운 + 카카오톡 전달용 메시지 자동 생성

### 🎨 디자인 & 애니메이션 고도화
- **하트/꽃가루 폭죽(Confetti) 효과**: `canvas-confetti` 연동, 수락 시 3단계 로맨틱 파티클 연출
- **초대장 카드 PNG 이미지 저장**: `html2canvas`로 스토리 카드 고화질(Scale x2) PNG 다운로드
- 모달 오버레이/토스트 캡처 잔상 방지 로직 적용

### 💬 카카오톡 SDK 연동
- Kakao JS SDK CDN 추가 및 `Kakao.Share.sendDefault()` 피드 카드 공유 기능
- `KAKAO_APP_KEY` 최상단 설정 변수 배치
- 카카오 앱키 미설정 시 안전한 클립보드 복사 Fallback 처리
- OG(Open Graph) 메타태그 설정 (카카오톡/SNS 링크 프리뷰 썸네일)

### 🐛 버그 수정

- `.toast` CSS 스타일 누락으로 하단 검은 띠 현상 → 플로팅 알약 팝업 스타일 복원
